# Детейлинг — 2 ролика по 10 секунд

Исходники: https://disk.yandex.ru/d/VpFuIp6jTxcDdw. Файлы `opisanie_*.md` найти не удалось, поэтому планы выбраны по кадрам из видео.

| Файл | Тема | Исходные папки |
|---|---|---|
| `detailing_01_moika_maybach.mp4` | Мойка Maybach: напор воды, пена на дисках и решётке, ручная мойка, руки в перчатках, финал с рамкой номера DETAILING AAA | «Мойка Майбаха», «Крупно руки с инстументом» |
| `detailing_02_keramika_g-class.mp4` | Керамика на G-классе: общий план, состав на аппликатор, нанесение, растирка микрофиброй, диск AMG, блеск кузова | «Керамика» |
| `detailing_03_moika_harley.mp4` | Мойка мотоцикла Harley-Davidson: пена из пеногенератора, пена на двигателе, мойка губкой, логотип на баке, смывка под напором, чистый мотор | «Мойка мотоцикла» |
| `detailing_04_tonirovka_vw.mp4` | Тонировка Volkswagen Lamando L: подготовка стекла водой, укладка плёнки, выгонка ракелем, финальная протирка, тонированное стекло, логотип VW | «Тонировка» |
| `detailing_05_anshlag.mp4` | «Аншлаг» для сторис: ночной заезд Audi RS 6 в студию → проход по залу, где одновременно моют и обслуживают много машин → вид через стекло лаунжа на мастеров → Audi проезжает мимо камеры. Проходы ускорены в 2–4 раза, без текста | «Аншлаг для сторис» |

Превью: `preview.jpg` (ролики 1–2), `preview_2.jpg` (ролики 3–4), `preview_anshlag.jpg` (ролик 5).
Ролик 5 собирается скриптом `make_anshlag.sh` по монтажному листу `edl_anshlag.txt` (в нём есть колонка скорости).

Формат: 1080×1920 (9:16), 30 fps, H.264 + AAC, ровно 10 с; по 8 склеек примерно по 1,1–1,5 с.
Обработка: лёгкая цветокоррекция (контраст, насыщенность, резкость), заголовок в первые 2,2 с, подпись «А-А-А ДЕТЕЙЛИНГ» с 8,5 с, звук с площадки нормализован (−16 LUFS), в конце затемнение.
Ролики 3–4 — без текста на видео (в `make_reels.sh` пустой заголовок отключает надписи).

`edl.txt` — монтажный лист: `id | путь на Диске | начало, с | длительность, с`.
`make_reels.sh` — скрипт сборки: вырезает фрагменты прямо по ссылкам с Диска (через публичный API) и собирает ролики.
